***Transforming Windows 11 to Windows 1.0!? (sorta)*** is an [AstroNT](AstroNT) video made by [AveryEclipse](AveryEclipse). The second video of "Wave 3", it revolves around using an NT Virtual DOS Machine (NTVDM) port to x64 to run Windows 1.0 apps on Windows 11 build 29634, the latest Windows Insider build released to Experimental Future Platforms at the time of recording (28 July-2 August 2026), then replacing Windows 11's Explorer shell with the MS-DOS Executive from Windows 1.0.

It is the 1st anniversary special (the channel was created exactly a year prior, on 17 September 2025). The premiere live chat of this video was the first place an invite link to the [AstroNT Datacenter](AstroNT_Datacenter) Discord server was ever posted, towards the end of the premiere.
