***Upgrading (directly) from Windows 7 to Windows 8.1!*** is a YouTube video made by [AveryEclipse](AveryEclipse) for the [AstroNT](AstroNT) channel. It was intended as one of the several filler videos produced as part of "Wave 2", alongside *[Converting a Windows Install to a VMware VM](Converting_a_Windows_Install_to_a_VMware_VM)* and *[Converting Windows XP to "Windows Server 2003" (on RTM!)](Converting_Windows_XP_to_"Windows_Server_2003"_(on_RTM!))*.

Released on 11 April 2026, the video demonstrates the fact truly upgrading directly from Windows 7 to Windows 8.1 is not actually possible by default (i.e. only available options being a clean install while keeping personal files or a clean install) unless a workaround is done using specialized software.

It showcases a Windows 7 installation on a VM with VMware Tools and a bunch of programs installed for the purpose of the experiment, which is then upgraded to Windows 8.1. The upgrade turns out successful with everything in place, albeit with the VMware Tools drivers not working, unless uninstalled then reinstalled again.

The video is among the fastest-growing AstroNT videos, having gotten 1K views within the first 24 hours of being uploaded. As of 14 September 2026, the total view count is 2,959.
