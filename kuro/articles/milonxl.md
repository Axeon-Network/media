**MiloNXl** (formerly known as **AstroNT Datacenter** from March to July 2026, **AstroNT Advanced Server**[^1] from October 2025 to March 2026 and originally **StuffyXP 2 Hangout**) is a private Discord server owned by [KitSixtyFour](KitSixtyFour) and [AveryEclipse](AveryEclipse) used for talk about current and future projects and plans. It was created on 16 September 2025 following the conception of the [AstroNT Workstation](AstroNT) YouTube channel.

The server was originally created for private talk regarding the development of the AstroNT channel, but later expanded to cover any sort of talk done by Kit and Avery a while after without any sort of rebrand. It is currently used for AstroNT and [Axeon Network](Axeon_Network)-related talk, alongside other private details. Additionally, it is also the source for many [Axeon KuroWiki](KuroWiki) or [Project Cuber](Cuber) builds.

# Overview
The server was originally known as **StuffyXP 2 Hangout** on September 2025 and was meant to be a place to discuss the development of the [AstroNT](AstroNT) channel, after such name was decided, the server was renamed not long after to **AstroNT Advanced Server** in October of the same year, and then renamed to **AstroNT Datacenter** on March 2026. This is the first AstroNT-branded project that changes the edition name in order to differentiate it from the YouTube channel, thing that would've been done again with the creation of the [AstroNT Embedded](AstroNT_Embedded) YouTube channel in June 2026.

However, due to the server losing its original focus of "a private AstroNT server" some months later after its creation, the server was renamed to **MiloNXl** on July 2026, shifting off original the AstroNT-only focus. The name "MiloNXl" comes from the nickname of Kit's Nintendo Switch Lite, which was sold to their sister on July 2026. Since Kit's sister didn't go through an OOBE due to the Switch not being formatted prior to being sold, the name is purely a coincidence, which matches with the name of the AstroNT mascot, [Milo Dan Novak](Milo). 

# Structure
Originally, the server only had two channels, `general` (text) and `General` (voice chat). On December 2025, the `video-planning` and `notepad` channels were added for their own self-explanatory uses. Following the revamp of the server on July of 2026, the channel structure was changed to the following:

- **Main**:
   - Only contains `general`.
- **[AstroNT Workstation](AstroNT)**:
   - Contains the `video-planning` and `extras` channels.
- **[KuroWiki](KuroWiki) & [Akane](Akane)**:
   - Contains the `wiki-planning`, `articles` and `build-dump` channels.
- **[Orchid](Orchid)**:
   - Contains the `global`, `bot-testing` and `build-dump` channels. (Not to be confused with KuroWiki & Akane's channel)
- **Miscellaneous**:
   - Only contains `notepad`.

The `General` voice channel was removed with the revamp.
