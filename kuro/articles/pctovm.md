***Converting a Windows Install to a VMware VM*** is a YouTube video made by [AveryEclipse](AveryEclipse) for the [AstroNT](AstroNT) channel. It was intended as one of the several filler videos produced as part of "Wave 2", alongside *[Converting Windows XP to "Windows Server 2003" (on RTM!)](Converting_Windows_XP_to_"Windows_Server_2003"_(on_RTM!))* and *[Upgrading (directly) from Windows 7 to Windows 8.1!](Upgrading_(directly)_from_Windows_7_to_Windows_8.1!)*.

Initially planned as a [Lynxmic](Lynxmic) video, it was recorded on 17-18 February 2026 on [TheHaswellLappy](TheHaswellLappy), the third video recorded on that laptop after the [Android x86](Android,_But_It's_on_the_x86_Architecture) and [8Store](The_Return_of_Windows_Store_in_Windows_8.1) videos, with the goal of archiving the Windows 8.1 Pro install used for the latter. The final goal was to have a VHD of the laptop's 128GB Kingston SSD contaning the Windows 8.1 Pro installation, which was then converted to VMDK for compatibility with VMware Workstation, all using specialized software.

As a filler video, it would be edited on-and-off, being finished and rendered on 1 April 2026. As of 15 September 2026, the video has 3,017 views.
