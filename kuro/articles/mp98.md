***Modern Programs on Windows 98! (w/ Linux X11 Servers)*** is a YouTube video made by [AveryEclipse](AveryEclipse) for the [AstroNT](AstroNT) channel. Released on 26 June 2026, it is a demonstration of X11's capability to passthrough apps from system A to system B. In particular, modern apps running on Arch Linux, the host OS running on Avery's main PC [AveryLappy](AveryLappy), are being passed through to a VMware VM running Windows 98 SE, a 28-year-old OS at the time of the video's release with the help of ancient X11 servers such as Xming (via KernelEx) and Hummingbird Exceed 10.

A Windows 95 VM was originally planned to be used for this video, however it was later decided to use Windows 98 instead due to the more limited options for an X11 server that can support modern Linux apps well enough on Windows 95, added by the lack of an Extended Kernel available for the operating system.

The penultimate video of "Wave 2", the video was recorded primarily on the 20th and 21th of June 2026, with one video footage dating from 23 June. As of 15 September 2026, the video has gotten 4,473 views.
